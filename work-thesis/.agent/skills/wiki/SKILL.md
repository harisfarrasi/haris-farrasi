# SKILL — Wiki (Catatan)

Gunakan skill ini saat pekerjaan menyentuh folder `wiki/`.

## Prinsip

- Utamakan perubahan kecil, jelas, dan mudah dicari.
- Jangan pindah-pindah struktur folder besar-besaran kecuali diminta.
- Kalau membuat format baru (mis. template note), buat satu file contoh dan iterasi.
