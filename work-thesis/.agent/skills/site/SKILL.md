# SKILL — Site (Next.js)

Gunakan skill ini hanya saat pekerjaan menyentuh folder `site/`.

## Baca dulu (minimal)

- `site/package.json`
- `.agent/workflows/w-site-nextjs.md`

## Checklist sebelum coding

- Jangan tambah dependency baru tanpa persetujuan eksplisit.
- Ikuti pola & style yang sudah ada di `site/`.
- Setelah perubahan, jalankan minimal salah satu:
  - `npm run build --prefix site`
  - `npm run typecheck --prefix site` (jika tersedia)
