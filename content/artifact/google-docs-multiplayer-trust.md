The breakthrough of Google Docs was not document editing. Word already proved people wanted that. The breakthrough was making a document feel like a **live room** instead of a static file.

Once multiple people can edit together, the core PM problem changes. The user is no longer asking, "Can I write?" The user is asking:

1. Who is here?
2. What changed?
3. Did my work get overwritten?
4. Can I trust this document as the latest truth?

That is why cursors, comments, version history, and autosave matter so much. They are not supporting features. They are the product's trust architecture.

## Product Lesson

In collaborative tools, confidence beats capability. If users trust the shared state, they forgive complexity. If they do not trust the shared state, every feature feels risky.
